# Прокси WSL → NL → USA

## Обычный запуск

Из WSL:

```bash
cd /home/dev/mihomo-proxy-kit
bash install.sh 149.28.240.154   # USA2
```

Для USA1 используйте `bash install.sh 108.61.222.91`.
IP в команде выбирает выход; вход остаётся NL: XHTTP `2083` для USA1 или `2087` для USA2.
Установщик проверяет, что фактический выходной IP совпадает с выбранным.

Локальная цепочка: приложение → Mihomo `127.0.0.1:7890` → Xray
`127.0.0.1:18080` → NL → выбранный USA. Xray на всех узлах версии 26.10.10
(проверено 2026-10-15: ядро 3x-ui на NL, Xray на USA1 и USA2).
Правила `.ru`, `.рф`, `local` и `localhost` направляют запросы напрямую.

После установки откройте новый терминал или выполните `source ~/.bashrc`.

## Где что лежит

| Путь | Назначение |
|---|---|
| `install.sh` | Установка и переключение между USA1 и USA2 |
| `vless.sh` | Получить актуальные XHTTP-ссылки для INCY с NL |
| `proxy.env` | Действующие параметры NL и SSH-адреса; содержит секреты |
| `proxy.env.example` | Образец параметров |
| `mihomo-keepalive.sh` | Служебный watchdog, используется установщиком |
| `bin/` | Локальные бинарники для установки без скачивания |
| `servers/` | Профили серверов, ссылки клиентов и доступ к панели |
| `tools/` | Административные скрипты; для переключения выхода не нужны |
| `profiles/` | Дополнительный профиль маршрутизации INCY |
| `backups/` | Создаётся при новом резервном копировании; прежние копии удалены по запросу 2026-10-15 |
| `docs/` | Архив прежней инструкции |

`.env` сохранён: его читают скрипты резервного копирования и восстановления.
Скрытые настройки IDE, агентов и памяти сохранены. Профили, ключи и резервные
копии не публикуйте; они исключены из Git существующими правилами.

## XHTTP

Получить актуальные ссылки для INCY из работающей конфигурации 3x-ui на NL:

```bash
bash vless.sh
```

Команда читает конфигурацию по SSH с ключами WSL, вычисляет публичный ключ
из действующего приватного ключа сервера и выводит ссылки в терминал.
Серверные настройки не меняются. UUID, SNI, short ID, порт и путь XHTTP
берутся с NL; параметры подключения к NL — из `proxy.env`.
Ссылки содержат данные доступа: не публикуйте вывод.

Для проверки реального трафика через каждый выход:

```bash
bash vless.sh --check
```

Результат сохраняется в `servers/vless-links-xhttp.txt` с правами `600`:

| Вход NL | Выход |
|---|---|
| `185.245.107.19:2083`, XHTTP + REALITY | USA1 `108.61.222.91` |
| `185.245.107.19:2087`, XHTTP + REALITY | USA2 `149.28.240.154` |

В WSL `install.sh` получает действующие параметры XHTTP с NL по SSH, запускает
локальный Xray 26.10.10 для соединения с NL и Mihomo для правил и порта `7890`.
Переключение выхода не меняет настройки серверов. Нужны доступ по SSH из WSL
к NL и локальные бинарники `~/.local/bin/xray` и `~/.local/bin/mihomo`.
2026-10-15 проверен `bash install.sh 149.28.240.154`: запросы через
`127.0.0.1:7890` к ipify и ChatGPT вышли с IP `149.28.240.154`.
Дополнительно `bash vless.sh --check` проверил из WSL оба XHTTP-входа:
2083 → `108.61.222.91` и 2087 → `149.28.240.154`.
Это проверка официальным Xray; показания пинга и совместимость конкретной
версии INCY отдельно не проверены.

## Команда proxy

Из корня проекта, без правок серверов, кроме `update`:

- `./proxy status` — версия Xray и состояние служб на NL, USA1, USA2.
- `./proxy logs [nl|usa1|usa2|all] [-n N]` — журналы серверов в одном выводе.
- `./proxy check` — проверка XHTTP-входов из WSL (`vless.sh --check`).
- `./proxy update ВЕРСИЯ [nl|usa1|usa2|all] [--yes]` — обновить Xray по одному серверу; после каждого проверка, при провале откат узла и остановка. Без `--yes` спрашивает подтверждение.

Команда `update` ещё не запускалась на реальных серверах: сначала проверьте её на одном USA.

## Обслуживание

Запускайте из корня проекта:

- `bash tools/install-server.sh N` — подготовить новый выход и добавить XHTTP-вход через API 3x-ui.
- `bash tools/backup.sh N` — резервная копия отдельного Xray на USA.
- `bash tools/restore.sh backups/ИМЯ_КОПИИ` — восстановление отдельного Xray на USA.
- `tools/unregister.sh` — прежний деинсталлятор Mihomo; не адаптирован к добавленному локальному Xray, для полного удаления текущей схемы не использовать.

`backup.sh nl` и `restore.sh` не обслуживают актуальную панель NL:
для неё нужна копия базы 3x-ui. Старая standalone-установка Xray на NL
удалена 2026-10-15 вместе с резервными копиями и файлами обновления.
На NL работает только установка под управлением 3x-ui; на USA — отдельный Xray.
После переноса `install-server.sh 2` проверен реальным повторным запуском
на USA2; установка на чистый сервер и восстановление резервных копий
в этой проверке не выполнялись.

## Проверка соединения

```bash
systemctl --user is-active xray-mihomo.service mihomo.service
curl --noproxy '' -fsS --max-time 20 -x http://127.0.0.1:7890 https://api.ipify.org
```

Текущий ожидаемый выход — `149.28.240.154` (USA2).
Маршрут WSL к NL, добавленный при восстановлении, временный: после полного
перезапуска WSL он может сброситься. Автозапуск локальных сервисов этого
маршрута не восстанавливает.
